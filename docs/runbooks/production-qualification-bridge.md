## Evidence and checks before execution

Record candidate SHA/tree, literal controller run ID, pipeline digest, installed policy/trust identity, target ownership, precise job-private project/database/store/ports, admission readback and artifact locations before mutating synthetic fixtures. Use the existing controller, not invented CI environment variables. Preserve first-attempt logs and bounded evidence indexes; do not publish test runtime configuration or private provider/secret material.

Source validators must keep rejecting internal-beta manifests/receipts where a production contract is required. Then qualify the exact final candidate through the approved controller and independently verify the installed policy and every external evidence row. Do not certify a gate solely because a template, simulator fixture or historical report exists.
