# Web component stories

## Files

- `README.md`: this Storybook inventory.
- `assets/`: images used by the example Storybook onboarding stories.
- `button.css`: example button story styles.
- `Button.stories.ts`: example button variants.
- `Button.tsx`: example button component.
- `Configure.mdx`: Storybook setup guidance.
- `header.css`: example header story styles.
- `Header.stories.ts`: example header states.
- `Header.tsx`: example header component.
- `page.css`: example page story styles.
- `Page.stories.ts`: example logged-in and logged-out page interactions.
- `Page.tsx`: example page component.
- `StaffScheduler.stories.tsx`: browser interaction contract for click-versus-drag, threshold, valid/outside/cancel paths, touch behavior, keyboard Move controls, accessible break markers, and published-shift locking.
